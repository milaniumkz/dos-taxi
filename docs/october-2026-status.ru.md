# Правки за 1–7 октября 2026: результат

| № | Правка | Результат |
|---|---|---|
| 1 | Старый казахстанский госномер | API и приложение принимают F261411 и другие поддерживаемые старые/новые форматы. |
| 2 | «Вместе» | Обычный тариф, создаётся в админке. Автоматического поиска попутчиков нет; водитель сам подбирает пассажиров по дороге. Выбранный тариф сохраняется в заказе и используется при итоговом расчёте. |
| 3 | «Детский» | Добавлен отдельный класс тарифа; водитель явно выбирает его при наличии детского кресла. |
| 4 | Блок бонусов | Уже реализованный блок сохранён и проверен. Для установленного старого приложения нужна новая сборка. |
| 5 | 20 заказов → 5 000 ₸ | Миграция устанавливает последние октябрьские условия. Бонус и запись выплаты сохраняются атомарно, повторный порог не оплачивается дважды. |
| 6 | SMSC | Существующая интеграция проверена. Реальная доставка зависит от действующих учётных данных, баланса, отправителя и шаблона SMSC. |
| 7 | Лимит SMS | Лимиты разделены по нормализованному номеру и IP; возвращается и показывается время ожидания. |
| 8 | Промокоды | Существующий полный путь расчёта и применения проверен на PostgreSQL: проценты/фиксированная скидка, ограничения, одновременные использования, итоговая цена. Добавлена инструкция выбора типа скидки. |
| 9 | Адрес подачи | Кнопка подстановки текущего GPS адреса удалена, ручной ввод адреса сохранён. |
| 10 | Тарифы новых городов | Существующее автоматическое создание базовых тарифов сохранено. Миграция добавляет недостающие записи старым городам, не меняя цены существующих тарифов. |
| 11 | Выбор тарифа в админке | Доступны четыре базовых класса, «Вместе» и «Детский». Дополнительные классы появляются в приложении после создания активного тарифа. |
| 12 | Получатели выплат | При ошибке API больше не подставляются демонстрационные водители. Получателя сверяют по имени и телефону. |
| 13 | Инструкции | Подготовлено руководство по городам, тарифам, заказам по телефону, бонусам, промокодам и выплатам. |
| 14 | App Store DOS Driver | Не затрагивался по указанию заказчика. |
| 15 | API Kaspi для пополнения баланса | Реализован HTTPS GET check/pay, подготовлены полные запросы, ответы, OpenAPI и правила сверки. Требуется согласовать домен/IP/параметры с банком; по умолчанию интеграция выключена. Данные карты не передаются. |
| 16 | Документы для партнёров | В руководстве приведён перечень документов и порядок уточнения требований. Юридические документы выдаёт владелец сервиса и соответствующие организации. |
