# Суточный бонус водителя

В админке «Настройки → Бонус за выполненные заказы» задаются количество заказов за сутки и сумма. Водитель получает **один бонус за календарный день**, сразу после достижения заданного числа завершённых заказов. Следующие заказы этого дня не дают второй бонус. В полночь прогресс начинается заново; вчерашние заказы не переносятся. Отменённые, незавершённые и заказы других водителей не учитываются.

Сутки: 00:00–00:00 в часовом поясе города водителя. Для старых профилей без города используется Asia/Almaty. Считается время завершения заказа (`completed_at`), а не создания. Границы календарного дня учитывают переходы часового пояса.

Повторное начисление защищено транзакционной блокировкой баланса исполнителя и уникальным индексом `(executor_id, bonus_date)`. История прежних бонусов и уже выплаченные суммы сохраняются; миграция отмечает существующие выплаты по календарным дням, чтобы не начислить повторный бонус в день обновления.

`GET /api/v1/executor/bonuses/progress` сохраняет существующие поля для старых приложений: `totalCompletedOrders` теперь содержит завершённые заказы текущего дня; `completedInCycle` ограничен дневной целью; `remainingOrders` достигает нуля и не запускает следующий цикл. Дополнительно возвращаются `bonusDate` и `timezone`.

Расчёт и начисление работают на сервере без обновления приложения. Новая формулировка суточных условий и исправленное положение маркера на карте требуют обновления установленного iOS/Android-приложения. В веб-приложении изменения доступны после серверной выкладки.

Миграция `1710000000032`: дата бонуса, уникальность по дню, сохранение исторических повторных выплат. При откате миграции суммы и записи остаются; прежний индекс по общему числу заказов восстанавливается без уникальности, поскольку дневные пороги повторяются.
