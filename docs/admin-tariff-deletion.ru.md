# Удаление лишних тарифов

Откройте «Города», выберите город и в разделе тарифов нажмите «Удалить» на нужной карточке. Подтвердите название тарифа. Также можно открыть «Тарифы», отфильтровать список по городу и удалить нужную запись.

Удалённый тариф исчезает из списков и недоступен для новых заказов. Запись и журнал действий сохраняются для истории поездок. Повторное удаление безопасно. Другие тарифы и города не изменяются.

API: `DELETE /api/v1/admin/tariffs/{id}`, Bearer JWT с ролью ADMIN, OPERATOR или SUPPORT. Ответ 200: `{"deleted":true}`; 401 без авторизации, 403 для остальных ролей, 404 для неизвестного тарифа. Автор и город записываются в журнал действий. Миграция 0033 добавляет nullable `tariffs.deleted_at`; удаление атомарно отключает тариф и устанавливает дату удаления. При откате миграции записи остаются выключенными.

После удаления класса сервер возвращает `TARIFF_NOT_FOUND` для его оценки цены, даже если в городе остаётся «Эконом» и в Redis ещё есть прежняя цена. Приложение скрывает такой вариант после повторного расчёта маршрута. Создание нового активного тарифа того же класса снова делает его доступным.

При расчёте маршрута без cityId сервер сначала использует настроенную зону обслуживания. Для городов без зоны он определяет населённый пункт по адресу подачи, сопоставляя русское и казахское названия. Неопределённый или неоднозначный населённый пункт не заменяется тарифами первого города. Параллельные запросы классов для одной точки используют общий запрос геокодирования.

Для картографических названий учитываются соответствия «Аральск» / «Арал» и «Айтеке-Би» / «Әйтеке би», даже если казахское имя в админке совпадает с русским.
