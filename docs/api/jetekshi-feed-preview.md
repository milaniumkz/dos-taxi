# Тестовая лента Жетекши

Операция `DOS Production Ops → seed-jetekshi-rides` создаёт ровно десять обозначенных тестовых заявок через обычные `/ride-requests/quote` и `/ride-requests`. Координаты находятся в Жетекши, внутри действующей зоны Павлодара. Новая зона/город не создаётся, действующие пассажиры не используются.

Для каждой заявки используется отдельная техническая учётная запись с зарезервированным идентификатором и не являющимся телефонным номером значением `TEST_JETEKSHI_01`…`10`. SMS и OTP не вызываются. Временные JWT используются только внутри контейнера и не выводятся в лог. Повторный запуск не дублирует открытые заявки; закрытые заявки не открываются заново. При коллизии технической учётной записи или неожиданных условиях операция прекращается.

Адреса и комментарии начинаются с «ТЕСТ» и указывают, что реальную поездку выполнять не нужно. Различаются количество мест (1–3), предложение цены и расстояние до подачи. Водители не назначаются автоматически. Заявки видны подходящим водителям города Павлодар с достаточным балансом и статусом «На линии».

Тестовые заявки после проверки можно отменить через администратора; не следует принимать их за реальные поездки.
