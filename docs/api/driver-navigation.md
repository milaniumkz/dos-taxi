# Внутренняя навигация водителя

Веб-версия: `https://dos.89.126.200.51.sslip.io/driver/`.

При назначении водителя экран активного заказа строит дорожный маршрут до подачи. В статусе ожидания цель остаётся прежней; после начала поездки цель автоматически меняется на место назначения. Завершение или отмена останавливают подсказки. Навигация не меняет состояние заказа, согласованную цену или расчёт бонусов.

Камера плавно следует за свежими GPS-координатами и разворачивает карту по направлению движения. Машина находится в центре открытой части карты между панелью навигации и карточкой заказа. Ручное перемещение карты отключает следование; кнопка со стрелкой возвращает его.

## HTTP

`POST /api/v1/geo/navigation` — JWT пользователя с ролью `executor`, `Authorization: Bearer <access-token>`.

```json
{
  "from": { "lat": 46.80123, "lng": 61.675111 },
  "to": { "lat": 46.813356, "lng": 61.644856 }
}
```

Также поддерживается необязательный массив `waypoints` (до восьми промежуточных точек). Координаты валидируются: широта −90…90, долгота −180…180.

Ответ `200`: прежние поля `polyline`, `points`, `distanceMeters`, `durationSeconds` и массив `maneuvers`. Каждый манёвр содержит `point`, `type`, необязательные `modifier`/`exit`, `roadName`, `bearingAfter`, `distanceFromStartMeters` — накопленное расстояние до начала манёвра. Типы/направления берутся из OSRM; фразы формируются приложением на выбранном языке. Старый `/geo/route` сохраняет прежний контракт без манёвров.

`401` — нет авторизации; `403` — другая роль; `400` — неверные координаты. Отсутствие дорожного маршрута возвращает `GEO_ROUTE_UNAVAILABLE`, сбой/таймаут провайдера — `GEO_PROVIDER_UNAVAILABLE`. Прямая линия вместо дорожной навигации не подставляется. Провайдер задаётся существующим `OSRM_BASE_URL` (по умолчанию публичный OSRM); требуется доступ сервера к нему.

## GPS и голос

Разрешите браузеру доступ к точной геолокации и звуку. Нужны HTTPS, активная вкладка и GPS устройства: браузер на настольном компьютере может выдавать только неточные координаты. Координаты с точностью хуже 60 м или старше 20 секунд не используются для навигации; при отсутствии свежего GPS подсказки останавливаются. Подтверждённое отклонение по трём точным измерениям вызывает перерасчёт, с интервалом не менее восьми секунд между запросами.

Подсказки выдаются при построении маршрута, примерно за 300 и 100 метров и перед самим манёвром; повторные GPS-события не повторяют ту же фразу. Расстояние считается по геометрии дороги, а не по прямой до поворота. Поддержаны повороты, развороты, развилки, слияния и съезды с кругового движения.

Нормальная скорость речи: `1.0` для Web Speech API и `0.5` по нормализованной шкале нативного `flutter_tts`; высота голоса `1.0`. Среди голосов выбранного языка приоритет отдаётся natural/neural/enhanced, затем доступным голосам Google/Microsoft.

Озвучка через `flutter_tts` использует системные/браузерные голоса: `ru-RU` для русского и `kk-KZ` для казахского. Автоматической подмены казахского русским нет. Если подходящий голос отсутствует, экран сообщает об этом; текстовые инструкции остаются на выбранном языке. Установите голос нужного языка средствами устройства и нажмите значок динамика, чтобы повторить проверку. Браузер может потребовать нажатия на динамик для разрешения воспроизведения. Голос можно выключить этой же кнопкой.

## Проверка веб-версии на телефоне

1. Открыть пассажирский и водительский режимы под разными аккаунтами. Разрешить геолокацию на телефоне водителя, вывести его на линию.
2. Создать заявку, предложить цену водителем и выбрать предложение пассажиром.
3. Проверить дорожный маршрут до подачи и подсказки на выбранном языке. Во время движения проверить вращение карты, ручное перемещение и возврат к машине.
4. Проверить ожидание у подачи, затем нажать «Начать поездку»: маршрут и подсказки должны переключиться на адрес назначения.
5. Безопасно проверить перерасчёт при изменении маршрута, отключение голоса, смену языка и остановку подсказок после завершения. Проверку экрана во время движения выполняет пассажир/наблюдатель.

Автотесты проверяют контракт и права HTTP, разбор OSRM, отсутствие фиктивного маршрута, GPS/перерасчёт, смену цели, этапы и отмену озвучки, языки и положение маркера на двух размерах экрана. Реальный звук и GPS необходимо дополнительно проверять на целевом телефоне: тесты используют управляемые координаты и голосовой адаптер.
