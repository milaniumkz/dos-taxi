# DOS: октябрьские изменения и инструкции

Материалы: переписка 1–7 октября 2026. «Вместе» — обычный тариф: водитель сам подбирает попутчиков по дороге. Автоматический подбор пассажиров, совместная очередь и несколько параллельных заказов не добавлены. Публикация DOS Driver в App Store исключена по указанию заказчика.

## Тарифы, города и автомобиль

1. В «Города» создайте/активируйте город. Базовые четыре класса такси, доставка и межгород создаются автоматически. Миграция добавляет недостающие базовые записи старым городам, сохраняя существующие цены и отключённые тарифы. Проверьте цены до начала работы в новом городе.
2. Для «Вместе» откройте «Тарифы → Создать тариф», выберите город, услугу «Такси», класс «Вместе». Заполните названия, цены, минимальную стоимость, ожидание и комиссию. Если тариф уже существует, используйте его: новый активный тариф создаёт следующую версию.
3. Для «Детский» создайте тариф того же города с классом «Детский (с креслом)». Водитель отмечает его в настройках автомобиля только при наличии кресла; изменение настроек может потребовать повторной проверки администратором. Поиск исполнителя учитывает включённые у водителя тарифы.
4. В DOS Driver откройте настройки автомобиля и отметьте доступные тарифы. Не отмечайте «Детский» без кресла. Номер автомобиля можно вводить современным или старым казахстанским форматом; пробелы, дефисы и похожие кириллические буквы нормализуются.
5. В форме заказа админки выбирайте город, услугу и класс отдельно. Поле «Услуга» содержит такси/доставку/межгород, поле «Тариф» — классы такси. Для сохранения нужен действующий тариф выбранного города.

## Регистрация и заказ другому человеку

1. Пассажир устанавливает DOS TAXI, водитель — DOS DRIVER. Введите номер Казахстана, запросите код и введите полученный SMS. Повторный вход при каждом открытии приложения не нужен: сессия сохраняется.
2. Защита от повторных SMS разделена: небольшой лимит для одного номера и общий лимит для IP. Пользователи одной мобильной сети не расходуют лимит одного номера. При исчерпании лимита показывается время повторного запроса.
3. Для заказа через админку откройте «Заказы → Создать заказ», выберите город, введите **телефон того клиента, который поедет**, имя, адреса подачи и назначения. Нажмите «Найти адрес» и выберите подсказки либо задайте координаты вручную. Выберите услугу, тариф и оплату; сохраните.
4. Для другого адреса подачи в пассажирском приложении отредактируйте поле «Откуда». Кнопка автоматической подстановки «Текущее местоположение» убрана. GPS используется для карты и подсказок, ручной адрес подачи сохраняется.
5. Заказы предлагаются водителям последовательно, не всем одновременно. Ответ на предложение — 20 секунд; отклонение или таймаут передают его следующему подходящему водителю. После неуспешного поиска выполняется повторная попытка.

## Промокоды

1. Откройте «Промокоды → Создать». Для скидки 20% выбирайте **процентную** скидку со значением 20. «Фиксированная» со значением 20 означает 20 единиц валюты, а не 20%.
2. Включите промокод, проверьте срок действия и максимум использований. Название кода вводится без лишних пробелов.
3. Пассажир вводит код на экране оплаты и нажимает «Применить». Сначала меняется расчётная стоимость, затем заказ создаётся со скидкой. Проверка цены не расходует использование, созданный заказ расходует.
4. Невалидный/истёкший/исчерпанный код показывает ошибку. Скидка не может превышать стоимость. Смена тарифа или маршрута требует нового расчёта и повторной проверки промокода.

## Бонусы и выплаты

1. В «Настройки» включите бонусы: 20 завершённых заказов → 5 000 ₸. Последняя октябрьская формулировка заменяет 15 заказов. Порог и сумма меняются в админке без новой установки приложения.
2. Блок на главном экране водителя показывает условия, прогресс и оставшиеся заказы. Он обновляется каждые 30 секунд, при смене баланса и возвращении в приложение. Старой установленной версии нужна новая сборка для появления этого блока.
3. Бонус зачисляется на внутренний баланс водителя; перевод на Kaspi вручную — отдельная операция. После каждого порога начинается следующий цикл.
4. В «Выплаты» выберите реального водителя по имени и телефону, задайте сумму и способ Kaspi/Halyk/наличные. Создайте выплату, выполните перевод, затем подтвердите выплату и списание. До перевода не подтверждайте.
5. При ошибке загрузки реальных водителей админка больше не подставляет демонстрационных получателей. Проверьте связь с API и права токена, затем повторите. Перед выплатой сверяйте телефон и валюту города.
6. Автоматическое пополнение баланса через Kaspi описано в [API документации](api/kaspi-online.md). Это входящий платёж, он не заменяет ручную выплату водителю.

## Документы для запуска в других городах

Лицензия, регистрация товарного знака и подтверждение прав на приложение не выдаются автоматически App Store или Google Play. Для запроса партнёра подготовьте договор на разработку и акт передачи, сведения о владельце/компании, политику конфиденциальности и условия сервиса, описание сервиса и реквизиты. Уточните точное название требуемого документа у партнёра или профильного органа Казахстана. Банковские договоры и юридические документы не публикуются в репозитории.

## Внешние условия запуска

На 7 октября сервер использует Wappi, данные SMSC не настроены. Для переключения создайте SMSC_LOGIN и SMSC_PASSWORD в секретах GitHub репозитория и выполните проверенный деплой. Рабочая доставка SMS требует оформленного аккаунта/договора, баланса SMSC, согласованных шаблонов/отправителя и проверки реального номера. HTTPS по IP сервера настроен, автоматическое продление сертификата включено. Для Kaspi остаются согласование IP источников и тесты endpoint с банком. Здесь подготовлен код и контракт; подтверждение договоров и доставка реальных сообщений проверяются отдельно и не подменяются тестовыми ответами.
